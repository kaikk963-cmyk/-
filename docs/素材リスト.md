# 素材リスト（立ち絵・背景）

アプリの「☰ → 素材」タブから取り込む画像の一覧。取り込んだ画像は端末のブラウザの中だけに保存される。
フリー素材でも、使う前に利用規約（クレジット表記・再配布・ギャンブル／パチンコ系での使用可否）を確認する。

## 画像の形式

| 種類 | おすすめ |
|---|---|
| 立ち絵 | 背景が透過したPNG。縦長（縦1000〜2000px程度）。顔が画像の上のほうにある全身か膝上 |
| 背景 | 横長でも縦長でもよい（液晶は縦3:横4より少し縦長）。暗めの絵だと図柄が見やすい |

大きな画像は取り込み時に長辺1100pxまで自動で縮める。
立ち絵は、図柄・予告カードでは顔のあたり（上から12%付近）を丸く切り抜いて、リーチ中は右側に大きく表示する。
