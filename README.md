# e東方幻想弾幕録

東方Projectの二次創作として作った、オリジナルのパチンコシミュレーター（スマホ向けWebアプリ）。
スペックと演出の信頼度は e東京喰種（2025）の解析値に合わせている。実際のお金は扱わない。
キャラクターは文字と紋で表現していて、原作の画像や音楽は使っていない。上海アリス幻樂団とは関係ない。

### 甘デジへの切り替え

画面右上のボタン（ミドル → 99ver. → 甘デジ → …）か、メニューの「スペック」タブでいつでも切り替えられる。

| | ライトミドル | 甘デジ 99ver.（この台の甘版） | 普通の甘デジ |
|---|---|---|---|
| 大当り確率 | 合算 1/199.9 | 図柄揃い 1/149.9＋チャージ 1/299.9（合算 1/99.9） | 1/99.9 |
| RUSH突入 | 約51%（突入チャレンジ） | 約50%（突入チャレンジ） | 100%（初当り後すべてST） |
| RUSH | 1/95.3・ST130（約75%） | 1/49.9・ST64（約73%） | 1/39.9・ST40（約64%） |
| 出玉（実獲得） | 10R 約1400／RUSH 約2800（3%で約5600） | 10R 約930／RUSH 約930（3%で約1860） | 4R 約370／ST中 4R 約370（50%で10R 約930） |
| 賞球 | 1&5&15 | 1&5&10 | 1&5&10 |
| 等価ボーダー | 約17.4回転 | 約17.0回転 | 約17.3回転 |

甘デジでは、実機の甘デジ版と同じく **ハズレ時の演出の出方はそのままで、信頼度のほうが上がる**（演出ごとの当否オッズに、大当り確率のオッズの比を掛ける）。
スペック表・演出ログ・開発者モードに出る信頼度もスペックに合わせて変わる。

## 遊び方

- **ハンドル**で打ち出し開始・停止（キーボードは H）。ヘソに入ると保留が貯まり、満タン時の入賞は無駄になる
- 実機と同じく**液晶は盤面の真ん中に埋め込まれていて**、玉はそのまわりを流れる。通常時は**左打ち**、RUSH・BONUS中は**右打ち**（盤面の下のボタンで切り替え。
  カスタムの「自動で切り替え」がONなら勝手に切り替わる）。左打ちの玉はレールに沿って盤面の上まで上がり、液晶の屋根から左へ落ちて、内レールの内側の釘を通る。左は 天釘 → 風車 → ワープ → 2段ステージ（上段 → 下段の溝）→ ヘソ と 道釘 → ヘソ の2ルート、
  右は電チュー・アタッカー。打ち出しの強さは開発者タブで調整できる。設定で盤面をOFFにすると、回転率の数字どおりに回る
- **PUSH**（Space）と **八卦炉レバー**（L）は、液晶の指示が出たときに押す。押さなくても数秒で自動で進む
- 持ち玉が尽きると自動で1000円（250発）を貸し出して投資に加算
- 右上の ☰ から、カスタム・設定・スペック表（全演出の信頼度）・データリセット

## カスタム

| カスタム | 選択肢 | 内容 |
|---|---|---|
| 先陰陽玉落下（先バレ） | OFF / 40% / 90% / EX | 保留入賞時に陰陽玉役物が落下。EXは落下すれば大当り＋RUSH濃厚。落下後にPUSHで裏ボタン |
| 先読み | なし / オススメ / チャンス / 熱 | 入賞時に見せる先読みの信頼度の下限 |
| レバブル | OFF / ON | ONで八卦炉レバーの振動が出やすくなる |
| インパクトフラッシュ | OFF / ON | 発生で大当り＋RUSH濃厚。ONで発生率アップ |
| RUSH演出モード | デフォルト / 陰陽玉突撃 / フラン襲来 / マスパ連打 | 告知の出方 |
| RUSH突入チャレンジ | 紅魔館突破 / 一発告知 | BONUS中のRUSH判定演出 |

## 開発者モード

メニューの「開発者」タブで、陰陽玉落下と先バレの出方をアプリ上で変えられる。

- 先陰陽玉落下（40%・90%・EX）、変動中の陰陽玉落下、西行妖の弱落下、SP発展時の落下、各リーチ中の落下、デバイス時の落下について、
  演出ごとに「信頼度」と「当たり時に出る割合」を%で入力できる。ハズレ時の出方は自動で決まり、出現頻度（約1/○回転）がその場で表示される
- 夢想封印MAX（6000発）の割合
- 復活演出の信頼度・出現割合
- 陰陽玉を今すぐ落とすボタン（通常音・低音・高音・弱落下）と、メイン画面への「役物投下」ボタン表示
- RUSHの強制終了（開発者タブ、またはメイン画面の開発ボタン）
- ヘソ釘の開き（ヘソで弾かれる割合。標準2.25で約20回転/1000円）
- 次に入賞する保留の結果を固定（大当り→RUSH／大当り→通常／チャージ／ハズレ）、先バレの強制（次の1回／毎回）
- 変更中は液晶右上に DEV と出る。「すべて元の値に戻す」で初期値に戻る

## 実機に近い動き

- 発射は1分100発。保留は最大4個で、満タン時の入賞は無駄になる
- 演出スピード「実機」（初期値）では、保留が少ないときのハズレ変動は約7秒、2個で約4.5秒、3個以上で約2.5秒に短縮される
- 大当りのラウンドは、右打ちした玉がアタッカーに10個入る（または30秒たつ）と閉じる。1カウント15発の払い出しで、閉じる直前のオーバー入賞も払い出す。
  右打ちしないと玉が入らず、出玉が減る
- RUSH中は電チューに入った玉で保留がたまる。RUSH終了後に残保留の抽選や時短はなく、通常時に戻る（e東京喰種と同じ）

## 立ち絵・背景の取り込み

メニューの「素材」タブで、キャラごとの立ち絵（14人）と背景（博麗神社・紅魔館・冥界）を端末の画像から取り込める。
図柄・カットイン・リーチ・予告カードに表示され、画像はそのブラウザの中（IndexedDB）だけに保存される。
欲しい画像の一覧は [docs/素材リスト.md](docs/素材リスト.md)。
「集合絵」の枠に大勢のキャラが写った絵を入れると、宴会予告の「全員集合」とRUSH突入のときに液晶いっぱいに出る。
「サウンド」タブで**効果音**を音声ファイルに差し替えられる（音量は自動でそろえる）。役物投下・先バレは「内蔵の音から選ぶ」（ポキュン・キュイン・ドン・キーン・ピロリン、すべてオリジナル合成音）でファイルなしでも変えられる。
取り込んだ音は頭の無音を詰めた最大8秒のモノラルWAVに変換して保存するので、動画ファイル（写真アプリの動画など）の音も使える。いちばん上に「役物投下ボタンの音」と「先バレの音」があり、
「役物を落としてみる」「先バレ（低音・高音）」ボタンで液晶に陰陽玉を落として確認できる（抽選には関係しない）。
「ほかの効果音」を開くと陰陽玉落下（通常音・低音・高音・弱落下）・先バレの低音／高音だけ・大当り・RUSH突入も別々に設定でき、
種類ごとの音がなければその場面の音 → 陰陽玉落下（共通）→ 標準の音の順に鳴る。
取り込んだファイルはリポジトリには入らないので、着信音サイトなどの素材でも規約の範囲で個人的に使える。

## セリフ

会話予告・リーチ発展時の相手のひとこと・霊夢のテロップ（色で信頼度が変わる）・クライマックスのモノローグ・仲間の声援・
復活・BONUS・RUSH突入／継続／終了などに、キャラごとの口調で書いたオリジナルのセリフが出る（`app/data.js` の `SERIFU`）。

## 保存

設定・プレイデータ・取り込んだ素材は端末のブラウザに保存し、claude.ai 上で開いたときはアカウント側（db・assets）にも保存する
（`app/cloud.js`）。スマホのアプリでブラウザの保存領域が消えても、開き直せば新しいほうのデータが戻る。
音声ファイルは assets が受け付けないので、JSON（base64）に包んで保存している。

## 演出の仕組み

当否を先に抽選してから、当否ごとの出現率で演出を選ぶ。各演出の「大当り時に選ばれる割合」をデータで決め、
ハズレ時の出現率を信頼度から逆算しているので、スペック表の信頼度はシミュレーション上でもそのまま再現される。

- `app/data.js` スペックと演出データ（信頼度・出現割合）
- `app/engine.js` 抽選・保留・演出シナリオの生成（DOMに依存しない）
- `app/stage.js` 液晶・リール・役物・弾幕エフェクトの再生
- `app/sound.js` 効果音とBGM（Web Audioで合成）
- `app/board.js` 盤面の物理演算（釘・風車・ワープ・ステージ・ヘソ・電チュー・アタッカー）
- `app/assets.js` 取り込んだ立ち絵・背景の保存
- `app/app.js` 打ち出し・BONUS・RUSHの進行と、データカウンター・メニュー

## テスト

```sh
node test/reliability.test.js        # 全演出の信頼度が設定値どおりか（モンテカルロ）
node test/reliability.test.js 1000000 ama99   # 甘デジ 99ver.（ama で普通の甘デジ）
node test/audit.test.js              # 全スペックの大当り確率・突入率・継続率・開発者タブの出現表示を実測と照合
node test/smoke.mjs                  # ブラウザで通しプレイ＋全演出ステップの再生（要 playwright）
node test/soak.mjs 60                # 盤面ON/OFF・全RUSHモードで長時間プレイし、エラー・停止・持ち玉の帳尻をチェック
```

## 動かす・スマホに入れる

```sh
cd app && python3 -m http.server 8000
```

GitHub Pages に公開する場合は、リポジトリの Settings → Pages → Source を「GitHub Actions」にして `main` にマージする
（`.github/workflows/pages.yml` が `app/` を公開する）。公開URLをスマホで開いて「ホーム画面に追加」するとアプリとして使える。
`app/` を更新したら `app/sw.js` の `VERSION` を上げる。

`node tools/build-artifact.mjs out.html` で、全部を1枚にまとめたHTMLも作れる。
