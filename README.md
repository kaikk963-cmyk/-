# マイク音量調整アプリ

スマホのマイク入力を **アプリ内で増幅・減衰** して、メーターで確認しながらモニター・録音できる Web アプリ（PWA）です。
iPhone（Safari）と Android（Chrome）の両方で動き、ホーム画面に追加すると普通のアプリのように使えます。

## できること

- **音量（ゲイン）調整**：-24 dB 〜 +24 dB（約 0.06 倍 〜 16 倍）。スライダーとプリセットボタン
- **レベルメーター**：入力（元の音）と出力（調整後）を並べて表示。ピーク表示と音割れ（CLIP）警告つき
- **リミッター**：音を大きくしても音割れしにくくする
- **モニター再生**：調整後の音をイヤホンで聞く（スピーカーだとハウリングするので注意）
- **録音・保存**：調整後の音を録音してファイル保存（Android: `.webm` / iPhone: `.m4a`）
- **ブラウザの音声処理の ON/OFF**：自動音量調整・ノイズ抑制・エコーキャンセル
- **マイクの選択**（端末が複数マイクを公開している場合）
- 設定は端末に保存され、オフラインでも起動可能

## 注意：OS のマイク感度は変更できません

iOS・Android ともに、一般のアプリが **端末全体のマイク感度** を変更する仕組みは用意されていません
（Android には API 自体がなく、iOS も内蔵マイクではほぼ変更不可）。
そのため、このアプリは「マイクから取り込んだ音をアプリ内で調整する」方式です。
**他のアプリ（LINE 通話・Zoom など）のマイク音量は変わりません。**

## スマホで使う方法

マイクは HTTPS でないと使えないため、GitHub Pages で公開するのが簡単です。

1. このリポジトリを `main` ブランチにマージ
2. GitHub の **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存
3. 表示された URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）をスマホで開く
4. 「マイクを開始」をタップしてマイクを許可
5. ホーム画面に追加
   - iPhone：共有ボタン →「ホーム画面に追加」
   - Android：メニュー →「ホーム画面に追加」/「アプリをインストール」

## パソコンで動作確認する

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く（localhost は HTTPS なしでもマイク可）
```

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | デザイン（スマホ向けダークテーマ） |
| `app.js` | 音声処理（Web Audio API）・メーター・録音 |
| `manifest.webmanifest`, `sw.js` | ホーム画面追加・オフライン対応 |
| `icons/` | アプリアイコン |

音声の流れ：

```
マイク → ゲイン → リミッター → ┬→ モニター（イヤホン）
                              └→ 録音
```
