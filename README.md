# 喰種パチシミュ

東京喰種のパチンコを手元で遊ぶための個人用シミュレーター（スマホ向けWebアプリ）。
実際のお金は扱わず、玉数は仮想。

## 遊び方

- 「回す」で1回転。「オート」で自動回転、「高速」で演出を短縮
- 持ち玉が足りなくなると自動で1000円（250玉）を貸し出して投資に加算
- 右上の ☰ からスペック確認とデータリセット
- データはブラウザに自動保存される

## 収録スペック（`app/specs.js`）

| 機種 | 初当たり | RUSH突入率 | RUSH | 継続率 |
|---|---|---|---|---|
| e東京喰種（2025） | 1/199.9 | 51% | 1/95.3・ST130回転 | 約75% |
| e東京喰種 超デカ超一撃ver. | 1/349.9 | 50% | 1/7.7・ST5回転 | 約50% |

確率は攻略サイト掲載値の近似。**出玉（`firstPayouts` / `rushPayouts`）は仮の値**なので、
実機に合わせて `app/specs.js` を書き換える。`[出玉, 重み]` を並べると振り分けになる。

## 自分の素材を使う

`app/assets/bg.jpg` を置くと演出エリアの背景になる（公式素材は同梱していない）。

## ローカルで動かす

```sh
cd app && python3 -m http.server 8000
```

同じWi-FiのスマホからPCのIPアドレス:8000 を開く。

## スマホにインストール

`.github/workflows/pages.yml` で `main` へのpush時に `app/` を GitHub Pages に公開する。
リポジトリの Settings → Pages → Source を「GitHub Actions」にしておく。
公開URLをスマホで開いて「ホーム画面に追加」するとアプリとして使える。

`app/` 内のファイルを更新したら `app/sw.js` の `VERSION` を上げると、スマホ側のキャッシュも更新される。
