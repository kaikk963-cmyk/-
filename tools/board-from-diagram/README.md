# 釘配置図から盤面を作る

`app/board.js` の壁・釘・入賞口・レーンは、実機の釘配置図（画像）から `gen_board9.py` で作っている。画像そのものはリポジトリに入れていない。

```
python3 gen_board9.py 図.png geom9.json 確認用.png
```

1. 図に書き込まれた赤い囲みを消す（下の線は補う）
2. 釘を丸の見本照合で拾い、図から消す（くっついて並んだ釘が太い壁にならないように）
3. 図の「玉が通れる白い部分」を、盤面の左の通路の1点から塗りつぶして取り出す（文字などの小さな島は白に戻す）
4. 実機で玉が通る・通らないのに図では区別できない所を直す
   - 内レール（太い灰色）の左はレーン側なので外す。レーンの出口のまわりの外レールは1本のなめらかな曲線にする
   - ステージの手前のふち（液晶の下の枠のいちばん下の線）は道釘の上にかぶさって描かれているだけなので壁にしない
   - 戻り玉防止弁・風車・ヘソ・電チューのベロは物理側で扱うので壁にしない。⑤のカップとサブデジの中は通れるようにする
   - 玉の入れない細いすき間（線と線のあいだの白い筋）は埋める
5. 壁でない飾りの線（ワープの通路の水色・ワープ出口の筒・液晶の下の線・ステージの手前のふち）も折れ線にして描くだけの線として出す
6. 通れる部分の境界線を折れ線にして、盤面の座標（幅300）に一様な縮尺で写す。盤面の底の線はアウト口として開けておく

geom9.json の値を `app/board.js` の定数（POLYS・PINS・LANE・RAIL・DECO・BLUE ほか）に入れる。
